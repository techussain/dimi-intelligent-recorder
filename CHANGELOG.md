# Changelog

Notable changes to Dimi Intelligent Recorder. Versions follow
[Semantic Versioning](https://semver.org/). Each version's section becomes its GitHub release
notes.

## [0.1.0]

First public release.

- **Recording:** screen or window, system audio (Windows), microphone and webcam, each on its own
  track, with clips growing on the timeline while you record. Pause / resume, countdown, region
  crop and a floating webcam self-view. A take interrupted by a crash is recovered the next time
  its project opens.
- **Editing:** multi-track timeline, text, shapes, animated elements, transitions, keyframes,
  colour adjustments, effects and blend modes; align / distribute, smart guides, transform and
  crop tools, layer order, copy / paste and paste attributes.
- **On-device AI:** English transcription with Whisper (downloaded once after you agree, from a
  pinned version checked against known checksums), captions with `.srt` export, and silence
  removal.
- **Export and projects:** MP4 and WebM export, autosave, `.irproj` project files and portable
  `.irbundle` archives (up to 4 GB).
- **Desktop app:** Windows and macOS installers, sandboxed with a strict Content Security Policy.
  No account, analytics or telemetry.
